# TaskFlow

> Sistema de gestão de tarefas diárias com calendário inteligente, recorrência automática e temas liquid glass.

🌐 **Site oficial:** [todo-calendar-eight-orpin.vercel.app](https://todo-calendar-eight-orpin.vercel.app)

## Funcionalidades

- Calendário diário para organização de tarefas
- Dashboard e gráficos de produtividade
- Tarefas positivas, negativas e recorrentes
- Área social e perfil do usuário
- Temas claro e noturno
- Interface responsiva em estilo liquid glass
- Avisos e suporte à instalação como PWA

## Tecnologias

- **Frontend:** React, TypeScript e Vite
- **Backend:** Java e Spring Boot
- **Banco de dados:** PostgreSQL
- **Deploy:** Vercel

## Executando localmente

```bash
git clone https://github.com/dhomini-db/todo-calendar.git
cd todo-calendar/frontend
npm install
npm run dev
```
